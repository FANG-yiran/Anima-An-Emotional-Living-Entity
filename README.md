# Anima · 情绪生命体交互评估系统

与一个拥有内部状态、记忆与不可解释性的情绪生命体进行 **90 秒自由交互**，系统实时监测每一次交互事件，并在结束后输出：

- **情感联结评分**（0-10）
- **关键词**（3-5 个）
- **七维关系画像**（0-100 分）
- **哲学性关系描述**（共情式、去标签化）

核心原则：不贴临床依恋标签，只描述交互中的关系体验。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:3000

## 交互流程

1. **开始页** → 点击「开始交互」
2. **90 秒自由交互**：移动鼠标靠近 / 远离 / 停住 / 点击触碰生命体；右上角实时监测面板展示内部状态轴、阶段、动作与事件日志
3. **问卷**：体验结束后弹出 7 题 5 点量表问卷
4. **报告**：情感联结评分 + 关键词 + 七维量化 + 关系描述

> 可以点击「提前结束 · 生成报告」按钮随时结束交互。

## LLM Agent 接入（可选）

系统内置规则引擎（关键词库 + 20 组文案模板匹配），无 Key 时开箱即用。

如需 LLM 生成更鲜活的关键词与关系描述，复制 `.env.example` 为 `.env` 并配置 OpenAI 兼容接口：

```bash
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.deepseek.com/v1   # 可选，默认 OpenAI
OPENAI_MODEL=deepseek-chat                    # 可选，默认 gpt-4o-mini
```

支持 DeepSeek / 通义千问 / Kimi / OpenAI / 本地代理等任何 OpenAI 兼容服务。配置后自动生效；请求失败或超时自动回退到规则引擎。

## 技术说明

- Next.js (App Router) + TypeScript + 原生 CSS，Canvas 渲染生命体（粗糙形态，可自行替换）
- 交互引擎：30Hz 鼠标采样 + 100ms 内部状态更新（4 核心轴：接近-回避 / 安全-防御 / 情绪强度 / 记忆-期待）
- 事件日志与会话汇总遵循 `lib/` 下的类型定义（见 `lib/types.ts`）
- 伦理声明：报告底部标注「本结果仅反映本次交互中的行为倾向，不构成心理诊断」
